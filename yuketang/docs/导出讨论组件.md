# 导出雨课堂讨论组件

1. 在油猴学习助手面板点击“暂停”，打开要适配的讨论页面，等已有评论显示出来。可先展开较长评论，确保有几条完整正文可见；不要输入或发送新评论。

请确认网址包含`/forum/`或`/discussion/`。`/video/`是视频页，即使左侧目录列出了“讨论”，也不是讨论区；新版导出器会拒绝在视频页运行。
2. 用编辑器打开项目根目录的`export-discussion-components.console.js`，复制全部内容。
3. 在讨论页按F12，打开Console（控制台），粘贴代码并执行。确认控制台显示代码本身，没有把文件名或Markdown代码围栏一起粘贴。
4. 浏览器会下载`yuketang-discussion-components-时间戳.json`。检查文件后把它发到聊天中即可。

脚本读取DOM组件树、类名、按钮/输入框结构、可见性和评论文字，不读取Cookie、LocalStorage、SessionStorage、框架内部状态或表单值，不调用网站接口、不代发评论。URL查询参数、常见作者字段、邮箱和手机号会过滤，但无法保证识别评论中的所有个人信息，请在分享前自行检查。

只导出当前已加载的评论，不会自动翻页或展开；跨域iframe会记录为不可访问。文件中的`truncated:true`表示达到体积上限，可在评论较少的页面再导出一份。

拿到实际组件文件后再核对评论正文选择器、去重抽样、200字限制、发送按钮及网站成功反馈，完成三种任务模式的适配。此前未验证的讨论改动尚未构建到可安装脚本。
