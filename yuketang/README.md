# 雨课堂学习助手

一个非官方 Tampermonkey 脚本，提供视频连播、课程材料整理，以及使用自备模型处理作业和讨论的辅助功能。当前版本：**1.14.0**。

使用前请阅读[免责声明](DISCLAIMER.md)。本项目与雨课堂及课程提供方无关联；使用者应自行确认课程规则与授权，并核对提交内容和平台记录。

## 功能

| 模式 | 主要操作 |
| --- | --- |
| 一键自动化 | 依次检查视频、讨论和作业；复用已确认的完成记录及已采集材料，补做未完成项 |
| 视频自动化 | 自动播放、倍速、静音、暂停恢复及连播；播放时记录页面上的知识导引和讲稿 |
| 作业自动化 | 单独收集材料或完成作业；可筛选单选、多选、判断、填空和问答题型 |
| 讨论自动化 | 读取最多三条不同的现有评论，由模型整理为200字以内的回复并按设置发布 |

面板分为**任务、材料、设置、诊断**四页，标题栏可拖动。任务页可暂停整个流程、单独暂停作业或讨论的自动提交，并显示当前步骤、处理原因和本轮进度。

确认提交不等于答案正确；本轮处理数不等于学校后台完成度。当前实现不自动处理考试或人机验证，模型也可能给出不准确的答案。

## 安装与更新

1. 在 Chrome 安装并启用 Tampermonkey。若浏览器提供“允许用户脚本”开关，请按 [Tampermonkey 官方说明](https://www.tampermonkey.net/faq.php?locale=zh&q=Q209)启用。
2. 新建油猴脚本，将 [yuketang-autoplay.user.js](yuketang-autoplay.user.js) 的全部内容粘贴进去并保存。更新时覆盖原脚本，不要同时启用两份。
3. 打开课程页面并刷新，等待右下角面板出现。脚本匹配 `yuketang.cn`、其子域名以及 `yuketang.tsinghua.edu.cn`；其他域名需要另行适配。
4. 选择任务后运行。自动播放受浏览器限制时，可手动点击面板的“继续播放”。倍速、静音或下一节按钮无法识别时，在“设置 → 视频播放与控件”重新标记。

覆盖更新会保留原有控件位置、课程缓存、材料选择、人工答案、提交记录和模型配置。切换浏览器、用户配置文件或站点域名后，本地数据不会自动迁移。

## 配置模型

视频播放和文字材料采集不需要模型；作业生成、讨论整理和特殊字体题目转写需要用户提供可用的模型 API。

1. 安装 Node.js 18 或更高版本。Windows 双击 [启动模型服务.cmd](启动模型服务.cmd)；其他系统在项目目录执行 `node tools/model-service.cjs`。保持服务运行。
2. 打开 [本地模型设置](http://127.0.0.1:8954/)，填写兼容 Chat Completions 的接口地址、完整模型名称和 API 密钥。接口地址可填写服务商提供的基础地址或完整 `/chat/completions` 地址。
3. 复制设置页的**本地连接口令**，在助手“设置 → 修改本地连接口令”中保存。该口令与服务商 API 密钥是两个不同的值。
4. 点击“检测服务”，再点击“测试模型回复”。前者检查本机服务和配置，后者实际发送一条短测试请求，可能消耗模型额度。

有特殊字体的题目首次转写需要支持图像输入的模型。独立题图没有通用识别保证；无法可靠处理时会跳过或提示。更新本地服务代码后，需要关闭旧服务窗口并重新启动。

## 材料与作答

任务页的“＋ 导入参考材料 / 管理材料库”或“材料”页签都可打开材料库，三种运行方式下均可使用。可选择本课程通用或当前章节材料，并单选或组合参考来源。默认优先级为：**本题人工答案 → 已勾选的用户材料 → 已勾选的同章课程材料**。

- 支持 MD、TXT、PDF 和 Word DOCX，单份不超过15 MB；也可以粘贴正文。旧版 DOC 请先另存为 DOCX。
- MD/TXT 在浏览器提取文字；PDF/DOCX 由本机服务调用 Python 解析。PDF 需要 Python 的 `pypdf` 包；扫描件、图片和公式不会自动转为可靠正文。
- 仅有 PDF 附件的图文页面会跳过正文等待，附件内容不会自动读入；如需参考，可自行导入文件。
- “材料 → 课程材料与缓存”可补采讲稿、更新当前材料、清除或重新采集课程缓存。清除课程缓存保留已导入文件、材料选择、人工答案和提交记录，可撤销上一次清理。
- 打开材料页时自动操作暂缓；完成编辑后返回任务页继续。作业页的“补充本题答案”可直接打开本题答案区。

作业默认自动提交，可提前点击“暂停自动提交”进行人工核验。网站返回错误时脚本暂停自动提交；用户核验后可以手动改正、点击“下一题”或恢复提交。未勾选题型不会请求模型或提交。题干模糊匹配位于“设置 → 作答策略”，默认关闭；连续两次匹配答案被判错会自动关闭。

## 一键流程与完成记录

点击“任务 → 一键自动化”，按**视频 → 讨论 → 作业**执行；作业先补齐所需材料，再处理选中的题型。视频阶段采集到的有效文字材料由后续作业复用。

脚本按课程保存阶段、确认的视频/讨论/作业记录及材料缓存，刷新后可继续。再次点击“检查并补做未完成项”会保留已确认的结果，并重新检查上轮跳过或缺失的内容；待确认、出错或部分题库不会被当作已完成。课程目录尚未加载、章节无法识别或页面有人机验证时会等待；目录点击后15秒未确认跳转会暂停，避免反复点击。

视频自然结束后如平台完成度未达到100%，脚本等待平台更新并尝试从头补播；连续两轮无进展或累计补播10次后按未完成跳过。实验性的“前台伪装”可在设置中关闭，不能保证后台播放一定被平台计入进度。**最终以网站实际记录为准。**

## 数据、隐私与备份

- 课程材料、题目、草稿、提交状态、参考库和人工答案保存在当前浏览器的 Tampermonkey 存储中，按课程隔离；它们不是项目源码文件。
- 本地服务仅监听 `127.0.0.1:8954`，API 密钥和本地口令存放在 `.local/model-service.json`。`.local/`、个人材料目录和日志不应上传或公开。
- 调用模型时，相关题目、选中的参考正文、讨论样本或转写图片会发送给你配置的模型服务商；不会主动发送雨课堂 Cookie。请先确认所用服务的数据处理方式和课程材料授权。
- “材料 → 导出本地记忆”会导出材料和处理记录，文件可能含课程正文；“诊断 → 导出调试文件”用于排错。分享前请自行检查文件内容。不要上传密钥、本地配置、个人答案库或未经授权的课程资料。

## 常见问题

| 现象 | 检查方法 |
| --- | --- |
| 没有面板 | 检查域名、脚本启用状态、油猴网站访问和用户脚本权限，再刷新 |
| 讨论或作业没有推进 | 查看任务页的当前状态和等待原因，确认目录已展开、自动化未暂停；必要时使用设置中的“识别当前目录项” |
| 本机服务正常但模型无回复 | 点击“测试模型回复”，核对接口地址、模型名、密钥和额度 |
| 材料不足或题目无法识别 | 检查所选材料是否覆盖题目，尝试补充本题答案；特殊字体需要具备图像输入能力的模型 |
| 网站显示错误或等待提交确认 | 核对网站反馈；错误会暂停自动提交，未确认记录不会重复提交 |

出现问题时可先在“诊断”导出调试文件，再刷新页面。运行事件保存在当前页内存，刷新会清除；课程缓存保留。

## 开发与验证

业务代码按 UI、视频、讨论、作业、AI 接入五个对象组织；公共页面适配和缓存工具位于 `src/shared/`。生成文件由源码构建，不应直接编辑：

```powershell
node .\tools\build.cjs
node --check .\yuketang-autoplay.user.js
node --test
```

上述完整回归命令针对本地开发目录。公开仓库暂时保留旧版测试文件，尚未同步本次完整测试套件，不能据此验证 1.14.0。

1.14.0 在同一轮询中复用目录结果，合并同章材料与题目完成度读取，并避免同步重复解析当前题目。同步导航后目录缓存立即失效，异步模型回复后仍重新核对题目和页面。功能与性能回归及真实课程适配限制见 [开发与测试](docs/DEVELOPMENT.md)；对象边界见 [架构说明](docs/ARCHITECTURE.md)，版本历史见 [更新记录](CHANGELOG.md)。
